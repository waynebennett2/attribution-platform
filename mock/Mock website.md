To enable a mock test/demo of the attribution project, we would need a mock website that consists of two pages, a landing page that has the logo and company description, and in the centre of the page a search option based on postal code input. A ‘Find a care home nearby’ search option in the centre of the page that allows for the input of a UK postal code and then when selecting the Find button, three care home options are displayed. Any UK postal code can be entered and the same three care homes will be displayed every time – it’s just for demo purposes.

**Care Home Search**

It is this phone number that will be replaced in the background with the 8x8 number from the our SQL DB table when the care homes page is displayed after the postal code is entered and the ‘Find Care Home’ search is selected.
