# docs/

`openapi.json` — the OpenAPI 3.0 document for every versioned REST endpoint the platform
exposes (Constitution Principle III: "All backend capability is exposed through versioned
REST APIs"). Generated by Swashbuckle from the live controller/DTO shapes in
`src/Attribution.Api`, not hand-written, so it can never drift silently from what the API
actually returns.

**Regenerating it** (whenever a controller or DTO shape changes):

```
dotnet run --project src/Attribution.Api
# then, from another shell, while it's running:
curl http://localhost:<port>/swagger/v1/swagger.json -o docs/openapi.json
```

(`<port>` is whatever `Now listening on: ...` logs on startup — Kestrel picks a random one
in Development unless `ASPNETCORE_URLS` is set.) The same document is also served live and
browsable at `/swagger` whenever the Api host runs in the Development environment.

The narrative wire contracts under `specs/001-call-attribution-platform/contracts/` remain
the authoritative *design* documents (what each endpoint means, why); this file is the
generated, exact *shape* of what's actually implemented.
